#  Serious Game : Compilation Rétro Python

**Cadre :** Projet réalisé en cours de Gestion de Projet  
**Thème :** Les jeux vidéo (Inspiration : anciens téléphones et calculatrices NumWorks)

##  Concept
Ce dépôt contient un jeu à but éducatif conçu comme une compilation de mini-jeux. L'objectif était de recréer l'expérience directe et addictive des jeux d'arcade portables classiques, tout en découvrant de A à Z le processus de création d'une application interactive complète en Python.

##  Objectifs d'Apprentissage & Philosophie
Réalisé à une période où mes bases en programmation étaient encore en développement, ce projet s'est concentré sur la **résolution de problèmes et l'intégration** plutôt que sur l'optimisation algorithmique pure :
* **Cohérence du Produit :** L'enjeu principal était de faire fonctionner ensemble des éléments distincts (avec beaucoup d'inspiration et de copier-coller de l'existant) pour créer une expérience fluide, logique et sans crash.
* **Résolution d'Erreurs :** Travail intensif de débogage pour s'assurer que tout soit raccord avec le reste et que le jeu soit le plus cohérent possible.
* **Découverte Technique :** Première prise en main concrète de la gestion de l'affichage graphique, des systèmes de menus et de l'intégration d'effets sonores en Python.

##  Architecture du Projet
Pour garder le contrôle sur le projet et structurer le code proprement, l'arborescence repose sur un découpage modulaire :
* **`main.py` :** Le chef d'orchestre du projet. Il gère le système de menus principal et relie tous les éléments entre eux.
* **Un fichier = Un jeu :** Chaque mini-jeu est isolé dans sa propre page Python dédiée.
